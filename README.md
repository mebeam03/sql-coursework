# SQL Coursework

Selected SQL queries from university database coursework using the course-provided **KimTay Pet Supplies** and **StayWell Property Management** teaching datasets.

These examples demonstrate `WHERE` filtering, nested subqueries, `EXISTS`, `INNER JOIN`, `LEFT JOIN`, four-table joins, aggregation, `GROUP BY`, `HAVING`, and `ORDER BY`.

## Featured examples

| Example | SQL skills |
|---|---|
| [StayWell: Washington owner rental summary](staywell/04_washington_owner_rental_summary.sql) | Joins, `COUNT`, `SUM`, `AVG`, grouping, `HAVING` |
| [StayWell: All properties and service requests](staywell/03_all_properties_service_requests.sql) | `LEFT JOIN`, optional relationships, sorting |
| [StayWell: Furniture replacement requests](staywell/02_furniture_service_requests.sql) | Four-table join, category filtering |
| [StayWell: Owners of two-bedroom properties](staywell/01_two_bedroom_property_owners.sql) | `IN`, `INNER JOIN`, `EXISTS` alternatives |
| [KimTay: Customer invoice and sales rep detail](kimtay/04_four_table_invoice_join.sql) | Four-table `INNER JOIN` |
| [KimTay: Good-credit invoice totals](kimtay/05_customer_credit_invoice_summary.sql) | Subquery, `GROUP BY`, `HAVING` |

## Query outputs

The [results folder](results/) contains three CSV outputs generated by running the selected StayWell queries against the course-provided sample records. The database creation and seed files are not redistributed. In GitHub, reviewers can inspect the query and its corresponding results.
